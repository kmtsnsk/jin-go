# 陣碁（Jin-Go）

囲碁をベースにした、空挺部隊を配置して陣地を広げるブラウザゲームです。
7・9・11路盤で、AI対戦と同じ端末での2人対戦ができます。

▶ **[ブラウザで遊ぶ](https://kmtsnsk.github.io/jin-go/)**

## 基本ルール

- 交互に小隊を1つ配置していきます。上下左右につながった小隊は1つの部隊になります。
- 相手の部隊を囲み、隣接する空き交点（退路）をなくすと撃破できます。
- 1つの部隊で空き交点を囲むと、その陣地に**軍旗**が立ちます。
- 1つの部隊で軍旗を2本立てると、その部隊は**要塞**になり、撃破されなくなります。
- 両者が続けてパスすると終了。盤上の自軍部隊と、自軍だけで囲んだ交点の合計が多い方の勝ちです。

詳しい操作はゲーム内の「遊び方を学ぶ」で、実際に盤を触りながら覚えられます。

## 囲碁との違い

中国ルールの面積計算を土台に、次の独自ルールを採用しています。

- **初期配置**：最初から双方に3子ずつ置いてあります。
- コミはありません。
- 終局時に死に石を取り除きません。必要な撃破は対局中に行います。
- 無条件の生存を支える「要塞」の領域には、両軍とも配置できません。

## 対戦AI
[KataGo](https://github.com/lightvector/KataGo) の学習モデル（g170-b6c96）を、[TensorFlow.js](https://www.tensorflow.org/js) でブラウザ内で動かしています。サーバーは使いません。モデルの読み込みと推論のコードは [web-katrain](https://github.com/Sir-Teo/web-katrain) をもとにしています。先読みは Jin-Go 用の独自の探索で、合法手と終局時の得点は Jin-Go のルールで計算します。強さは 4 段階です。
